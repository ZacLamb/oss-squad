Privacy

Last updated: 21 November 2026

Dungeon Conga is a free game that runs in your browser. We keep this simple: we do not collect your personal information.

What we collect

There are no accounts, no ads, no analytics, no tracking pixels and no cookies set by the game. We only receive data in the two cases below, and neither includes your name, email, location or any ID that identifies you or your device.

Crash reports

If the game hits a technical error, it sends us an anonymous crash report so we can fix the bug. A report contains only: the error message and the line of code where it happened, the game version, the floor you were on, your screen size, your device's language setting, and your browser type and version. We group identical errors together and delete reports after 90 days. We do not store IP addresses with them. You can turn crash reports off any time in Settings → Send crash reports.

Optional cloud save

If you choose to use Settings → Cloud save, your game progress (scores, unlocks, settings and gold) is stored on our server under a random code such as K7QX-M2PA. Anyone who has the code can load that progress, so keep it private. Nothing is uploaded unless you turn cloud save on.

What is stored on your device

Your best score, your banked gold, unlocked heroes and perks, settings and any saved run are kept in your browser's local storage on your own device. You can erase it any time with Settings → Reset all progress, or by clearing this site's data in your browser.

Offline use

The game installs a service worker so it can run offline. It only stores the game's own files on your device.

Hosting

Like any website, the host may keep standard server logs (such as IP address and requested page) for security and reliability. We do not use these logs to identify players.

Children

The game contains cartoon fantasy combat and no chat, purchases or links to other services.

Publisher

Dungeon Conga is published by Revenue Generating Solutions LLC.

Changes

If we ever add features that handle data (for example optional online leaderboards or purchases), we will update this page first and say so clearly.
